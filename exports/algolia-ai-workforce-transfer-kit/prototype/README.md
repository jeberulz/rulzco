# Algolia AI Workforce Prototype

This directory is a standalone Next.js prototype. It has no runtime connection
to Algolia systems and uses synthetic data throughout.

## Run locally

```bash
npm install
npm run dev
```

Open:

- `http://localhost:3000`
- `http://localhost:3000/ai-workforce`

## Checks

```bash
npm run typecheck
npm run build
```

## Current implementation

- Employee onboarding for Alex Morgan, Staff Product Designer
- Today and human decision queue
- Durable Strategy context
- Goal and plan hierarchy
- Tasks, routines, and execution runs
- AI Team map and specialist inspector
- Skills, context, tools, and templates library
- Artifacts and evidence review
- Inbox, activity provenance, and settings
- Explicit simulation and human-approval boundaries
